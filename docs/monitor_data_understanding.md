# 监控接口输入数据理解

> 来源：`text.txt` —— 公司内网监控系统接口的一次返回快照
> 数据时间：2026-03-16 14:47（采集时间戳 `timestamp: 1773643737753`）
> 顶层结构：`{ status, statusText, message, timestamp, data: [ ...监控项 ] }`
> `data` 是一个数组，每个元素是一类监控项；下面按 `monitor` 字段逐项说明。

---

## 字段约定

每个监控项通常包含：

| 字段 | 含义 |
|---|---|
| `monitor` | 监控项中文名 |
| `code` | 状态码：`1` = 无异常 / `2` = 有数据或存在异常 / `-1` = 接口查询失败 |
| `type` | 对当前状态的文字描述 |
| `message` | 该项的详细数据，结构因 `monitor` 而异 |

| 字段 | 含义 | 量纲 |
